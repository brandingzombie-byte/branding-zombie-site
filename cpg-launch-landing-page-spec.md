## IMPLEMENTATION NOTES FOR CLAUDE CODE

### General
- This is a single page to be added to the existing brandingzombiedesigns.com site
- Match the existing site's tech stack, fonts, and global styles
- Page should be fully responsive (mobile-first)
- All CTA buttons link to a single Calendly URL (Gerry will supply the link)
- Page route suggestion: `/launch` or `/cpg-launch`

### Image Placeholders
- Use styled placeholder containers with dashed borders and descriptive alt text
- Include image dimension suggestions where possible (e.g., hero: 1200×600, case study cards: 800×500, headshot: 400×500)
- Case study section should support an image carousel or gallery per card for future implementation

### Design Direction
- Clean, confident, premium. Not agency-flashy — founder-trustworthy.
- Plenty of whitespace. Let the copy breathe.
- Dark background hero section (charcoal/black) with light text for impact
- Light background for body sections
- Subtle accent color for CTAs — something that pops without being aggressive
- Typography: Strong sans-serif for headlines, readable body font. If the existing site has type choices, defer to those.

### Performance
- Lazy-load all images
- Minimize external dependencies
- Optimize for Core Web Vitals (this page needs to load fast from a LinkedIn click on mobile)

### SEO
- Page title: "CPG & Supplement Packaging Design — Shelf-Ready in 30 Days | Branding Zombie"
- Meta description: "From concept to shelf-ready in 30 days. Label design, FDA compliance, print production, and vendor coordination for CPG and supplement brands."
- Use semantic HTML (h1, h2, h3 hierarchy as outlined above)
- Alt text on all image placeholders
